How to run

Launch notes

Everything points to the live waitlist. Attribution + budgets are in ADS_PLAN.md.

Slideshows: the first 3–4 slides are relatable stock-style photos — add the listed on-screen text in CapCut/TikTok photo mode. The final 2–3 are the Selv frames (text already baked in). Keep each slide ~1.5–2s, use a trending sound.

Destination: https://selv-waitlist.vercel.app + the per-creative UTM shown on each ad. The landing writes the UTM into Supabase waitlist.source, so you can see which creative drove each signup.

Guardrails: avatar is a styling tool, not a body-scorer; varied bodies & skin tones; no "unlimited wardrobe" on Free (Free = 25 items); no Phase-2 social-feed promises.

Before paid scale: add a TikTok Pixel + Meta Pixel to the landing (flagged in ADS_PLAN.md).
