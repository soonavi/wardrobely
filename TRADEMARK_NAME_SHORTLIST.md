# Trademark / Availability Knockout Screen — Round 2 (Coined Names)

**Date:** 2026-07-15

> **PRELIMINARY SCREEN ONLY — THIS IS NOT LEGAL ADVICE.** This is a fast, best-effort web-search knockout pass to cut obviously dead names before spending money. It is **not** a substitute for a full USPTO TESS clearance search, a common-law/state search, or review by a trademark attorney. Absence of a hit in these searches does NOT mean a name is legally clear — it only means nothing obvious surfaced in ~2 searches per name. Do not file, brand, or spend on any name below without full clearance first.

## Background

Round 1 (Twinit, Fitcast, Mimic, Fitroom, Wardro) all failed knockout — Fitroom and Wardro are live same-category apps, Mimic is crowded, Twinit is an existing software company. This round tests 10 **coined/fanciful** names (stronger trademarks, avoiding descriptive fashion roots like fit-/wardrobe-/closet-/twin-/mimic-/drobe-/style-/dress-) for a Gen Z photoreal 3D-avatar virtual-wardrobe app.

## Result vs. requirement

3 of 10 candidates came out **CLEAR** (Selv, Persa, Faela) — meets the "at least 3 clear" bar, so no additional brainstorm names were required this round. 2 came out **CAUTION** (Vessa, Vayb) and 5 came out **TAKEN/AVOID** (Modl, Reve, Myx, Ovie, Loomi) — all five have a live, same-or-adjacent-category app or a live registered software/media trademark, which is exactly the disqualifying pattern from Round 1.

## Top picks (ranked)

1. **Selv** — Cleanest screen of the three, and the strongest brand story: "selv" is Scandinavian for "self," giving an instant, on-the-nose semantic link to a personal-avatar/identity app without touching a descriptive fashion root. Short, four letters, easy to say and spell.
2. **Persa** — Equally clean screen; evokes "persona," which fits an avatar-identity product almost as well as Selv, with a softer, more feminine/Gen-Z sound.
3. **Faela** — Cleanest screen of all (zero commercial use found anywhere), fully coined so it carries no built-in meaning — safest from a pure trademark-strength standpoint, but requires more brand-building since it doesn't hint at "self/avatar" the way Selv or Persa do.

**Recommendation: lead with Selv**, with Persa as the backup if Selv stumbles in full USPTO clearance (e.g., if a live Class 9/42/25/35 filing turns up that this quick pass missed).

## Next step

Run a full USPTO TESS search plus common-law/state trademark search on the winning name (starting with **Selv**), then get attorney clearance before any spend. If clear, file Intent-to-Use applications in **Class 9** (downloadable software/apps) and **Class 42** (SaaS/non-downloadable software), and grab the matching **.com/.app domain and @handle the same day** clearance completes to prevent squatting.
