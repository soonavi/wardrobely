# Deep Name Verification — "Selv"

> **Preliminary, not a legal clearance opinion.** Based on public web + app-store searches (July 2026). I can't authoritatively query the USPTO TESS database, WHOIS, or the social platforms from here — the items marked **[confirm directly]** need a 2-minute manual check or an attorney. A live same-category app or a phonetically-identical registered mark in a related class is what would kill a name; read the verdict with that lens.

## Verdict: **Promising — proceed to attorney clearance, with one thing to resolve**

Selv clears the single most important test the last shortlist failed: **there is no same-category app and no obvious software/tech brand using the name.** That already puts it ahead of Fitroom/Wardro/Mimic/Twinit. The catch is a set of **phonetic neighbors in fashion apparel** — most notably a footwear brand spelled "Selve" — that a trademark examiner *could* raise because your product is fashion-adjacent. That makes Selv a "clear-with-caveats," not a slam dunk. It's worth a real clearance, not a blind commit.

## Risk by axis

- **Same-category app:** ✅ none found — the key positive.
- **Software trademark (Class 9 / 42):** ✅ nothing obvious surfaced. **[confirm via TESS across 9, 42, and phonetic variants]**.
- **Apparel trademark (Class 25):** ⚠️ phonetic neighbors exist (Selve, Selvi). Your goods are *software*, not clothing, so it's about "relatedness," not identity — arguable either way. This is the one item an attorney should clear.
- **Domain:** ⚠️ `selv.com` is a 4-letter .com — those are essentially all registered/held, so assume it's **not freely available [confirm WHOIS]**. Plan on `selv.app`, `getselv.com`, or `tryselv.com`.
- **Handle `@selv`:** ⚠️ 4-letter handles are scarce; likely taken/reserved **[confirm on IG/TikTok]**. Plan on `@selv.app` / `@getselv` / `@selvapp`.
- **Distinctiveness / strength:** ✅ In the US, "selv" (Danish/Norwegian for "self") is arbitrary/fanciful → a **strong, protectable mark** for a software app.

## Recommendation

**Green-light Selv for a professional clearance** — it's the best-positioned name we've tested. Before committing spend:
1. **Attorney or full TESS search** across **Classes 9, 42, 25, 35**, explicitly including phonetic equivalents **Selv / Selve / Selvi / Selva**. The specific question to answer: does "Selve" (or any live apparel mark) block "Selv" for a *software application*? If that comes back clear, you're good.
2. **Confirm the practical assets [do today]:** check `selv.com` / `selv.app` (WHOIS), and `@selv` on IG + TikTok. If the short forms are gone, decide your fallback (`getselv` / `tryselv` / `selv.app`) *before* you brand anything.
3. If clear → file **Intent-to-Use in Classes 9 + 42**, and grab the domain + handles the same day.

**If the "Selve" footwear conflict makes you nervous:** the other two names that came back clean — **Persa** and **Faela** — had *no* phonetically-identical apparel neighbor, so they'd carry slightly less relatedness risk. Selv is the strongest *brand*; Persa/Faela are marginally safer *legally*. Any of the three is a defensible choice.
